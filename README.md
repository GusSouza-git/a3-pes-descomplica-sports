# Marco-3-Decisão-Arquitetural

Neste marco está todo conteúdo relacionado ao marco 3, que é sobre decisões de arquitetura. Ou seja, o Registro de Decisão Arquitetural (ADR) do projeto, com as tecnologias escolhidas e o motivo de cada escolha.

O documento está na versão 1.0 e reúne 8 decisões (ADR-001 a ADR-008): arquitetura em quatro camadas, linguagem e frameworks, API e autenticação, banco de dados, pagamento, expiração da reserva, autorização e hospedagem. Ele se baseia no Documento de Requisitos 1.0 e nos diagramas do Marco 2.
