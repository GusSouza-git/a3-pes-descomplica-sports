# Marco 0 — Termo de Abertura

## Objetivo da entrega

O Marco 0 apresenta o Termo de Abertura do Descomplica Sports, projeto acadêmico da A3 de Projeto e Engenharia de Software. O documento estabelece a proposta de facilitar a busca e a reserva de quadras esportivas e apoiar os proprietários na divulgação e na organização dos espaços.

## Conteúdo

O Termo de Abertura reúne o problema, o objetivo, o escopo previsto, as funcionalidades futuras, as entregas e seus marcos, os riscos iniciais e a distribuição dos papéis no grupo.

Ele serve como referência inicial para o desenvolvimento da documentação e da modelagem do projeto. As regras e os requisitos detalhados são tratados no Marco 1.
